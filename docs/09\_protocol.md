# 연구질문 
"중1-고3 청소년의 주중 수면시간 부족(8시간 미만)이 권장 수면시간 충족군(8-10시간) 대비 주관적 학업성적에 미치는 인과적 효과를 평가하기 위한 역학 분석 연구"
1) 순서형 방식 : 청소년기의 학업 성취도는 명확히 두 부류로 이분화되기보다 연속적인 성적대 스펙트럼에 가까움. 따라서 5단계 척도를 자의적으로 끊어 정보를 손실시키기보다는 순서형 로지스틱 회귀분석을 사용하는 것이 통계적 검정력을 최대화할 수 있음.

2) 비교군 -보건당국 권장 청소년 적정 수면시간인 '주중 8-10시간'을 충족하는 청소년 집단 
- 기준군 : 주중 평균 수면시간 8-10시간 (권장 수면 충족군)
- 노출군 : 주중 평균 수면시간 8시간 미만
- 학년이 올라갈수록 한국 청소년의 수면시간이 급격히 줄어드는 특성을 고려하여, 생리학적 적정 수면을 취하는 8시간 이상 집단을 기준으로 두고 수면 부족 정도에 따른 학업성적 위험도를 비교하는 구조

3) 효과 추정 종류
- 총효과 : 수면 부족이 학업성적에 미치는 인과적 영향은 주간 졸음, 집중력 저하, 우울·불안 등 다양한 매개 경로를 거쳐 종합적으로 나타남. 따라서 본 연구는 이러한 매개변인을 통제하지 않고, 수면 부족이라는 노출 자체가 학업성적에 미치는 전체적인 인과적 영향력의 크기를 평가하고자 총효과를 선택.
  
# 예상 방향
본 연구는 주중 수면시간(노출)이 청소년의 주관적 학업성적(결과)에 미치는 정방향의 인과 경로를 가정한다. 즉, 충분한 수면은 인지 기능과 집중력을 유지시켜 학업 성취에 긍정적인 영향을 미칠 것으로 예상됨. 그러나 동시에 본 연구는 역방향 인과성(Reverse Causality)의 가능성을 내포하고 있음. 즉, 수면 부족이 성적을 떨어뜨리는 경로뿐만 아니라, 학업 성취도가 높거나 학업 부담이 과중한 학생들이 성적 유지 및 향상을 위해 스스로 수면시간을 줄이거나, 반대로 성적이 부진한 학생들이 학업 스트레스로 인해 수면 장애를 겪는 경로가 공존할 수 있음. 따라서 본 횡단면 분석 결과는 인과관계의 선후를 단정하기보다 수면의 양과 주관적 학업 성취 간의 통계적 연관성을 확인하는 데 의의를 두며, 향후 종단적 연구를 통한 인과성 검증이 필요함을 본 연구의 한계이자 고려사항으로 둠.

# 역할 분담
-**김민서:** 
  * 연구질문 내 비교군 및 효과 추정 종류 설정
  * 변수 정의표 작성 및 관리
  * 통계 분석 코드 초안 작성

-**한지윤:** 
  * B-1 예상 방향 및 역방향 인과성 고찰 작성
  * 사용 자료, 연도, 복합표본 가중치(`W`, `STRATA`, `PSU`) 선정 근거 작성
  * 분석 대상 선정 계획(포함·제외 기준) 및 역할 분담 섹션 작성

# 사용 자료·연도·가중치

1) 사용 자료 및 연도
-사용 자료: 청소년건강행태조사(Korea Youth Risk Behavior Survey, KYRBS) 원시자료
-조사 연도: 2025년

2) 선택한 가중치 및 선정 이유
-선택 가중치 변수: `W` (원시자료 내 단년도 분석용 가중치 변수)
-선정 이유: 청소년건강행태조사는 층화집단추출법(Stratified Cluster Sampling)으로 표집된 복합표본설계 자료임. 이용지침서 기준에 따라, 단년도(2025년) 전체 표본을 대상으로 청소년 인구를 추정할 때는 단년도 분석용 가중치(`W`)를 적용해야 모집단(대한민국 중1~고3 청소년)에 대한 대표성 있는 비편향 추정치를 얻을 수 있음.

3) 층(Strata) 및 집락(PSU) 변수
-층화 변수 (Strata): `STRATA` (표집틀 층화 변수)
-집락 변수 (PSU): `PSU` (1차 추출단위 - 학교/학급 집락 변수)
-복합표본 분석 설정: 파이썬 분석 시 단순 무작위 추출(SRS)을 가정하지 않고, `STRATA`, `PSU`, `W` 변수를 반영한 복합표본분석(Complex Survey Design Analysis) 설정을 적용하여 표준오차 과소추정을 방지하고 통계적 타당성을 확보.

# 변수 정의표
수면시간과 주관적 학업성적 연구 변수 정의표

| 변수 | 유형 (교란/매개/충돌부/무관) | 근거 |
| :--- | :--- | :--- |
| **grade** (학년) | 교란 | 학년이 올라갈수록 학업 부담과 입시 환경으로 인해 수면시간이 줄어들고 성적 분포 양상도 달라지므로 두 변수 간 교란 작용을 함 |
| **sex** (성별) | 교란 | 성별에 따른 생리적 수면 패턴의 차이와 주관적 학업성적 응답 성향에 영향을 미치는 공통 원인임 |
| **income** (가구 경제 수준) | 교란 | 가정의 경제 수준은 수면 환경(수면시간)과 사교육 인프라 접근성(학업성적) 모두에 영향을 미치는 공통 원인임 |
| **study_time** (주당 학습시간) | 교란 | 학습 시간이 많을수록 수면시간은 감소하고 주관적 성적은 높아질 수 있으므로 두 변수 간 교란 작용을 함 |
| **stress** (스트레스 수준) | 매개 | 수면 부족은 스트레스와 우울감을 유발하고, 이는 다시 학업성적 저하로 이어지는 중간 경로(매개 변인)임 |
| **attention** (수업 집중도) | 매개 | 수면 부족으로 인해 주간 졸음이 발생하고 수업 집중도가 떨어져 학업성적 하락으로 이어지는 중간 경로임 |
| **special_act** (심화 학습반 참여) | 충돌부 | 수면이 부족한 상태이면서도 성적이 우수한 특정 그룹에서 선택적으로 더 많이 참여하는 등, 두 변수의 공통 결과(Collider)임 |
| **height** (키) | 무관 | 청소년의 신체 성장 지표인 키는 주중 수면시간과 주관적 학업성적 간의 직접적 인과 경로에서 교란이나 매개 역할을 하지 않음 |
