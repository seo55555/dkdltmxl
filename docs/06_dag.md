# B-1

| 변수명 | 유형 | 설명 및 인과적 근거 |
| :--- | :--- | :--- |
| `age` (연령) | 교란변수 | 흡연율은 젊은 층에 쏠려 있고 고혈압 유병률은 고령층이 높으므로 흡연과 고혈압 모두에 영향을 주는 대표적 교락 요인 |
| `male` (성별) | 교란변수 | 성별은 흡연 행태 및 고혈압 유병률 모두에 공통적으로 영향을 미침 |
| `edu_n` (교육수준) | 교란변수 | 사회경제적 위치는 흡연율과 건강 관리 능력(고혈압)에 동시에 영향을 미침 |
| `exercise` (신체활동) | 매개변수 | 흡연이 신체활동 수준에 영향을 주고, 신체활동은 혈압에 영향을 미치므로 인과 경로 상의 중간 단계 변수 (`smk_cur → exercise → htn`) |
| `prog` (질병 경과/치료력) | 충돌부 | 흡연과 고혈압 두 요인의 공통 결과 지점이 되는 변수 (`smk_cur → prog ← htn`) |
| `family_htn` (고혈압 가족력) | 무관 | 고혈압 발생에 직접적인 원인이 되나 흡연 여부와는 인과적 연결이 없어 백도어 경로를 형성하지 않는 변수 |

보정집합 결정 근거
교란 경로 차단 (Confounder Control): 연령(age)과 성별(male)은 흡연율과 고혈압 유병률 모두에 공통으로 영향을 미치는 대표적 교란변수이므로, 백도어 경로를 차단하기 위해 반드시 보정집합에 포함한다.

비만도(obes) 보정 반영: 비만도는 흡연의 결과로 나타날 수 있는 경로와 고혈압의 위험 요인으로 작용하는 경로를 동시에 가지므로, 팀 과제의 분석 설정에 따라 공변량으로 함께 보정하여 교란 편향을 통제한다.

최소 보정집합 원칙: 불필요한 충돌부(Collider)를 배제하고, 설정된 핵심 공변량들(age, male, obes)로 신뢰할 수 있는 총효과 추정 모델을 구성한다.

#### DAG 화살표 목록

```
age -> smk_cur          age -> htn
male -> smk_cur         male -> htn
edu_n -> smk_cur        edu_n -> htn
smk_cur -> exercise     exercise -> htn
smk_cur -> prog <- htn
smk_cur -> htn
family_htn              (어느 변수와도 인과 화살표 없음)
```

# B-3

복합표본 로지스틱 회귀분석 결과, 연령, 성별, BMI를 통제하기 전 무보정 모형(M1)에서 현재흡연의 오즈비(OR)는 1.154(95% CI: 1.004-1.327, SE=0.071, p=0.045)였으나, 이들 교란변수를 보정한 기본 보정모형(M2)에서는 OR이 1.464(95% CI: 1.228-1.745, SE=0.090, p<0.001)로 상승하여 흡연과 고혈압의 연관성이 더욱 뚜렷해졌다. 이러한 추정치의 변화는 인과구조상 연령, BMI와 같이 흡연과 고혈압에 동시에 영향을 미치는 교란변수가 흡연의 효과를 실제보다 낮게 보이게 하는 방향(음의 교란, 억제 효과)으로 작용하고 있었음을 시사하며(M2에서 연령 OR=1.074, BMI OR=1.096, 모두 p<0.001), 이를 모형에 투입해 통제함으로써 흡연이 고혈압에 미치는 총효과가 왜곡 없이 교정되었음을 보여준다. 반면 M2에 매개변수인 신체활동(exercise)을 일부러 추가로 보정하여 직접효과를 추정한 모형(M3)에서는 OR 추정치가 다시 달라지는데, 이는 DAG상 흡연이 신체활동을 거쳐 고혈압에 이르는 인과 경로(smk_cur → exercise → htn)가 존재하기 때문이다. 즉 exercise를 통제하면 이 매개 경로를 통한 간접효과가 차단되어 직접효과만 남게 되므로, M2와 M3 사이의 추정치 차이는 흡연이 신체활동을 매개로 고혈압 발생에 기여하는 몫만큼 효과가 분산된 결과로 해석할 수 있으며, 이는 인과구조를 통해 충분히 설명된다.
